## How the report groups these references

- TinyML / TinyissimoYOLO foundation: papers 1–4
- Closest UAV / multiclass detection setup: papers 5, 6, 10, 11
- Knowledge-distillation foundation: papers 7–9
- YOLO11 small-object / multiclass image processing: papers 13–17
- Real hardware / edge deployment: papers 1–4, 7, 11, 15–17

The report cautions against comparing reported mAP values across papers unless dataset, test split, IoU convention, and evaluation protocol are consistent.
